# Salary Analysis by Country and Race

A data analysis project that explores salary distributions across different countries and racial groups using Python. The project applies exploratory data analysis (EDA), data preprocessing, and visualization techniques to identify compensation trends and demographic patterns.

---

## 📊 Project Overview

The objective of this project is to analyze salary data and investigate how compensation differs across various demographic groups. Through statistical analysis and data visualization, the project provides insights into salary distributions, potential disparities, and key trends.

The analysis focuses on:

- 🌍 Salary distribution across different countries
- 👥 Salary comparison among racial groups
- 📈 Identification of trends, outliers, and salary patterns
- 📊 Data visualization for easier interpretation

---

## 📁 Dataset

**Dataset:** Salary dataset containing demographic and compensation information.

The dataset includes attributes such as:

- Country
- Race
- Salary
- Occupation
- Experience Level
- Additional demographic features

## 🔍 Analysis Workflow

### 1. Data Cleaning
- Handled missing values
- Removed duplicate records
- Processed categorical variables
- Prepared data for analysis

### 2. Exploratory Data Analysis (EDA)
- Generated descriptive statistics
- Examined salary distributions
- Identified outliers
- Compared demographic groups

### 3. Data Visualization
Created visualizations including:

- Salary distribution histograms
- Box plots
- Bar charts
- Heatmaps
- Correlation analysis

### 4. Key Insights
The analysis helps identify:

- Salary differences between countries
- Compensation variations among racial groups
- Salary distribution trends
- Potential demographic disparities
